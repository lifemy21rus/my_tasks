# Скриншоты интерфейса 2.0

Снимки сделаны автоматически на демо-профиле (`scripts/seed-demo.js`) в светлой и тёмной темах.

## Как переснять

```bash
npm run shots
```

Скрипт создаёт временный профиль с демо-данными, запускает приложение в режиме съёмки
(`MYTASKS_SHOTS_DIR`) и копирует готовые PNG в `docs/screenshots/`.

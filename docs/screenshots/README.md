# Скриншоты для релиза 2.0.0

Каталог для актуальных скриншотов интерфейса версии 2.0 (используются в документации/релизных материалах).

## Рекомендуемый набор
- **Главное окно (список):** задачи, фильтры, поиск, теги-чипы, индикатор умного списка.
- **Канбан:** колонки статусов, карточки, drag-and-drop.
- **Календарь:** режимы месяц/неделя/день, навигация, задачи со сроком.
- **Умные списки и теги:** боковая панель/фильтры, сохранение и применение списка, справочник тегов.
- **Модалка задачи/заметки:** статус, теги, вложения, подзадачи/поля.
- **Вложения:** список вложений, открытие/удаление.
- **Настройки:** резервные копии/восстановление, статистика и лента активности (фильтр), тема/параметры.
- **Миграция 1.x → 2.0:** уведомление об успешном обновлении (при наличии сценария).

## Примечания
- Делать скриншоты на чистом/демо-профиле (`scripts/seed-demo.js`) в целевой Windows-среде.
- Предпочтительно PNG, понятные имена файлов (например, `01-list.png`, `02-board.png`).
- Перед съёмкой убедиться, что отображаются актуальные строки/элементы UI версии 2.0.0.

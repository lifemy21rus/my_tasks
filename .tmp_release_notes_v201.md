## v2.0.1

Патч с исправлениями внешнего вида интерфейса 2.0.

### Исправлено
- **Сайдбар:** устранено наложение блока «Настройки» на разделы фильтров; сайдбар прокручивается целиком.
- **Фильтр по срокам:** свой диапазон дат свёрнут под кнопку-календарь (поля компактные), раскрывается при выборе даты.
- **Канбан:** заголовки задач больше не сжимаются до одного символа (приоритет перенесён в мета-строку, действия вынесены из потока).
- **Календарь «Неделя»:** убран горизонтальный скролл, календарь использует всю ширину окна.

### Дополнительно
- Автосъёмка интерфейса: `npm run shots` (демо-профиль, светлая и тёмная темы).
- Скриншоты интерфейса 2.0 в `docs/screenshots/`.

Подробности: `CHANGELOG.md`.

# Contributing

Привет! Мы рады любым вкладам в проект «Мои задачи».

## Как начать

1. Сделайте форк репозитория.
2. Создайте ветку для вашего изменения: `git checkout -b feature/ваша-спецификация`.
3. Внесите изменения и закоммитьте их.
4. Отправьте Pull Request в основную ветку.

## Стиль кода

Проект использует ESLint и Prettier. Перед отправкой PR запустите:

```shell
npm run lint
npm run fmt:check
```

Если есть ошибки, исправьте их:

```shell
npm run lint:fix
npm run fmt
```

## Тесты

Запустите тесты перед отправкой PR:

```shell
npm test
```

E2E-тесты (требуют Windows):

```shell
npm run e2e
```

## Коммиты

Сообщения коммитов пишите на русском языке, в значащем стиле:

- `feat: добавлено шифрование data.json`
- `fix: исправлена версия портативного дистрибутива в README`
- `docs: обновлён CHANGELOG`

## Сообщения об ошибках

Если вы нашли уязвимость безопасности, пожалуйста, не публикуйте её открыто.
См. [SECURITY.md](./SECURITY.md).

# Политика безопасности

## Поддерживаемые версии

| Версия | Поддерживается |
| ------ | -------------- |
| 1.0.3  | ✅             |
| < 1.0.3| ❌             |

## Сообщение об уязвимости

Если вы обнаружили уязвимость в приложении «Мои задачи», пожалуйста:

1. Не публикуйте информацию об уязвимости в открытом доступе (issues, публичныеフォрумы и т.д.).
2. Свяжитесь с авторами репозитория через GitHub (создайте приватный issue или напишите_maintainer_).
3. Опишите проблему подробно: шаги воспроизведения, ожидаемое и фактическое поведение.

## Безопасность данных

- Все данные хранятся локально в `%APPDATA%\MyTasks\data.json`.
- Приложение не подключается к интернету.
- Опциональное шифрование `data.json` (AES-256-GCM) защищает файл паролем из переменной `MYTASKS_DATA_PASSWORD`.
- **⚠️ Важно:** при потере пароля шифрования данные невозможно восстановить. Пароль не хранится в приложении.

## Релизы

Релизы публикуются в разделе [Releases](https://github.com/lifemy21rus/my_tasks/releases).
Установщик не имеет цифровой подписи кодом, поэтому Windows SmartScreen может показывать предупреждение.
Это планируется исправить при получении сертификата кодовой подписи.
